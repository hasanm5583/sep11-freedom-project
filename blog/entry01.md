# Entry 1 
##### 11/9/26 

### Content
I have decided to use the tool of Phaser for my freedom project. Which I tinkered with the code to be able to see the physics of phaser and how a spirit can bounce off corners and how to make sprites. My game will be a karate PVP game. Of one of my karate teachers vs another one of my karate teachers. Using the [Phaser](https://phaser.io/oss/docs/phaser/concepts/actions) website to learn how to make a sprite and make it move across certain coordinates.  I briefly considered using  [Kaboom](https://kaboomjs.com/doc/intro) but since phaser has a guide on physics and sprites in games I decide to go with phaser

### Engineering Design Process 
The First Step in the EDP is to define the problem I hope to solve through my karate PVP game that most people don't feel confident enough to start karate. Especially since there are no PVP karate games out there for karate unlike other games. I will use my two karate teacher Shian Allan Acosta, and myself with permission given. to make avatar sprites of them in phaser. 

### Skills
One of the skills I used when deciding to make a karate PVP game was creativity. This a game that is currently non existent. I took a simple love of games and a love for karate to make a game that never has existed before with two new players no one has played with before. 

 Another skill that I had to implement was Consideration. I had to consider who would be playing my game and why, was it because they love karate or might want a visualization of what doing karate might feel like. For example  I wanna play this game because I still love karate even though I don't have as much time to train as I would like.
